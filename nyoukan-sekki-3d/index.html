尿管結石 排石大作戦 -3D-

右の腎盂にできた結石(シュウ酸カルシウム)を、腎盂 → 尿管 → 膀胱 → 尿道と進めて体外へ排出しよう。

  • 💧 水を飲む:尿量が増えて石を押し流す。ただし閉塞中は腎盂内圧が上がり、激しい疝痛に…
  • 🦘 ジャンプ:振動で石を動かし、狭い所を突破する。体力を消費
  • 🚽 排尿:石が膀胱に落ちたら、尿をためて勢いよく押し出そう(男性の尿道は長い)
  • 💊 NSAIDs:鎮痛 / 🌿 α1遮断薬:尿管平滑筋を弛緩 / 🍋 クエン酸製剤:結石の成長を抑制

尿管には3つの生理的狭窄部(①腎盂尿管移行部 ②総腸骨動脈交差部 ③尿管膀胱移行部)があります。

⚠ 脱水で結石は成長します。水腎症が続くと発熱・尿管ステント留置、10mm超でESWL、3日で出なければTULに。

🧍 人体を右斜め前から立体表示。ドラッグ / ← → で視点を回転、ダブルクリック / [R] で元に戻す。[L] でラベル表示切替。皮膚や尿路は半透明なので、石や尿の流れが透けて見えます。
